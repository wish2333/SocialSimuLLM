# SocialSimuLLM 展示流程与说明

> 本文件仅用于展示准备，不会被前端读取。

## 展示目标

在 8–10 分钟内回答四个问题：为什么要做这个系统；社会科学理论怎样进入仿真配置；研究者如何在运行中形成对照与介入；系统怎样从原始行为记录形成有边界的研究解释。

核心叙事不是“做了一个多 Agent 小镇”，而是“把理论变量、实验控制、微观过程证据和机制分析接成了一条可复核的研究链路”。

## 展示前检查

1. 启动后确认侧栏默认进入“研究档案”，页面没有错误提示。
2. 依次打开七个页面，确认论文研究案例与微观工程快照均能加载。
3. 保持离线模式；展示过程不需要 API key，也不会发起模型调用。
4. 浏览器缩放建议 90%–100%，窗口宽度至少 1280px。
5. 提前记住证据边界：论文正式设计为 10 Agent、10 地点、5 分支、单分支 420 轮；paper 分支当前归档了其中两组完整记录；没有重复实验和显著性检验。

## 推荐流程（8–10 分钟）

### 0:00–1:00　项目总览

打开“项目总览”。先讲研究问题：现实观察很难让同一群体从同一状态反复接受不同技术与政策刺激，因此需要可克隆、可介入、可追踪的社会仿真实验环境。

用四个数字建立规模感：10 个异质 Agent、10 个研究空间、5 个动态分支、单分支 420 轮。随后指出页面同时保留了两层证据：论文案例负责研究设计与分析，十轮微观快照负责证明工程运行链路，两者的数据不混用。

### 1:00–2:00　技术路线与 Agent 设计

快速打开“技术路线”和“Agent 设计”。只讲一条闭环：配置进入 Runner，Agent 每十分钟经历感知、记忆检索、规划、行动、写回与反思，事件和状态进入 JSONL 与 checkpoint。

强调 Agent 并非只有人格提示词：身份、经济条件、日程、关系、地点资源和既有目标共同决定其可见信息与行动条件。这些差异是后续解释角色异质性的基础。

### 2:00–4:00　实验设计

打开“实验设计”。先看“理论到仿真实体”：个人、技术、组织、环境变量分别映射到角色描述、地点条件、关系网络和定时事件。

在五分支选择器中依次点开自然发展、部分技术接触、全体技术接触、激励政策与限制政策。讲清共享基线的价值：Day 1 先自然运行；Day 2 从同一状态分出不同技术接触强度；Day 4 再施加不同政策；Day 6 统一归档。研究者能够控制介入时间、对象、强度和方向，但不会直接替 Agent 决策。

展示只读 YAML 预览，说明可配置项包括模型、向量模型、记忆上限、运行轮次和输出产物。此处不要进入“实验工作台”真正启动运行。

### 4:00–6:00　运行与介入

打开“运行与介入”，先讲论文归档。GE/NA 是仓库目录标签，项目没有保存其正式全称，因此界面按事件内容称呼归档组。展示两组均运行至 Day 6、420 轮，并说明原始材料包括完整日志、记忆、阶段摘要与事件文件。

指出二次编码口径：分母是每组 4,200 条主行动，词项计数来自完整日志；记忆文件会复制同地点可见行动，因此不拿 memory 词频当采纳率。GE 中 IVModel 词项行动为 1,014，NA 为 130；这说明两组文本议题轨迹存在明显描述性差异，但单次生成不能推出总体效应或统计显著。

再切到微观回放，拖动 step，点开一个 Agent 的行动、短时计划和印象。用这一段证明宏观指标可以下钻到具体角色与时间点，而不是只展示总结文字。

### 6:00–8:30　结果分析

打开“结果分析”。建议按以下顺序：

1. 描述性对照：比较分时词项与角色异质性，先回答“发生了什么”。
2. 机制证据：展示事件注入、角色感知、讨论、场景评估与行为改变的证据链。
3. 三重耦合：社交网络把信息转成协作，场景需求把技术属性转成情境价值，政策响应体现选择性适应。
4. 反例与边界：外围角色低响应、组织变量表现不足、安全顾虑弱化、校外组过度绝缘。
5. 下一步检验：重复运行、编码一致性、网络指标、不同模型与种子稳健性。

这一页最重要的表达是：分析助手的价值不是替研究者“自动下结论”，而是把现象、跨组比较、理论机制、反例、证据强度和后续检验组织在同一工作台中。

### 8:30–9:30　工程演进与收束

最后打开“工程演进”，用三个版本概括从可运行原型、认知模块化到研究平台化的过程。收束到三个工程选择：离线研究档案保证展示稳定；结构化日志和 checkpoint 保证过程可追踪；严格的数据契约防止把缺失字段或论文解释伪装成新的实验结果。

## 常见追问

### “这能证明真实人群也会这样吗？”

不能直接证明。当前结果是理论导向的探索性过程证据，可用于提出机制、发现反例和设计后续研究，不能替代真人样本的外部效度检验。

### “1,014 对 130 是采纳率吗？”

不是。它是完整日志中含 IVModel 词项的主行动数，分母为每组 4,200 条主行动。页面刻意称其为词项编码，不称采纳率。

### “为什么只展示两个归档组，论文有五个分支？”

论文描述了五分支正式设计；当前 paper 分支保留了两组完整终态记录。页面分别标注“设计规模”和“已归档覆盖”，没有把两组伪装成五组。

### “研究者能控制到什么程度？”

可以控制角色与关系、地点资源、时间粒度、模型与记忆参数、事件的时间/对象/强度/方向，并能从 checkpoint 克隆分支；不能直接指定 Agent 必须采取某个行动。

### “分析助手目前实现了吗？”

在线研究工具已有摘要、模式、假设和跨运行比较入口；研究档案页展示的是目标分析范式及已固化证据，不应声称所有论文级编码与因果检验都已经自动化。

## 结束语

SocialSimuLLM 的重点不只是生成看起来像人的行为，而是让社会科学研究者能够明确配置假设、控制介入、保存过程、比较分支，并对解释强度保持诚实。
